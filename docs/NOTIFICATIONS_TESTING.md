# ทดสอบการแจ้งเตือน TravelDiary

## การทดสอบบนมือถือ

1. เปิด API และแอป เข้าสู่ระบบ ไปที่โปรไฟล์ → การแจ้งเตือน
2. เพิ่มข้อความพร้อมวันและเวลาในอนาคต อนุญาตแจ้งเตือน ตรวจว่ารายการปรากฏ แก้เวลาแล้วตรวจว่าเหลือรายการเดียว
3. กดทดสอบ 3 วินาที กลับหน้าจอหลัก รอแจ้งเตือน แล้วแตะ ต้องเปิดหน้าเพิ่มบันทึก ทดสอบทั้งตอนแอปเปิดและตอนเริ่มแอปจากแจ้งเตือน (ไม่ใช้ Force stop)
4. ยกเลิกรายการที่รอแจ้ง แล้วตรวจว่าไม่แจ้งเมื่อถึงเวลา
5. สร้างบันทึกวันที่วันนี้ในปีก่อน เปิดย้อนความทรงจำและเลือกเวลาที่ยังไม่ถึง ต้องเห็นครั้งถัดไปเป็นวันนี้
6. สร้างอีกทริปที่ตรงวันเดียวกันในปีก่อน กดทดสอบย้อนความทรงจำ ต้องได้แจ้งเตือนเดียว แตะแล้วแสดงสองบันทึก ถ้ามีทริปเดียวต้องเปิดรายละเอียดโดยตรง
7. เปลี่ยนวันที่หรือลบทริป ตรวจว่าตารางความทรงจำเปลี่ยน ปิดสวิตช์แล้วไม่เหลือการเตือนความทรงจำ
8. ปฏิเสธสิทธิ์ ตรวจข้อความอธิบายและปุ่มเปิดการตั้งค่า เปิดสิทธิ์แล้วกลับแอป/ลองใหม่
9. ออกจากระบบก่อนถึงเวลา ตรวจว่าการเตือนถูกยกเลิก เข้าบัญชีอื่นต้องไม่เห็นรายการเดิม กลับบัญชีเดิมจะคืนรายการที่ยังไม่หมดเวลา
10. แตะแจ้งเตือนเมื่อเซสชันหมดอายุ เข้าบัญชีเดิมและรอโหลดบันทึก ต้องไปหน้าที่เกี่ยวข้อง เข้าบัญชีอื่นต้องไม่เปิดข้อมูลของบัญชีเดิม

## ขอบเขต

- การตั้งเวลาใช้เวลาท้องถิ่นของเครื่อง ณ เวลาจัดตาราง และคำนวณความทรงจำใหม่เมื่อกลับเข้าแอป
- ไม่ติดตามตำแหน่งเบื้องหลัง ไม่ส่ง Push และไม่เพิ่ม permission สำหรับ exact alarm
- ระบบประหยัดพลังงานและการปิดแอปแบบ Force stop อาจชะลอ/หยุดการแจ้งเตือน
- ทดสอบอัตโนมัติครอบคลุมการจัดกลุ่ม วันอธิกสุรทิน ขีดจำกัดตาราง การเปลี่ยนบัญชี การแก้ไข/ยกเลิกและหน้าตั้งค่า แต่ไม่ยืนยันการส่งจริงบนอุปกรณ์
